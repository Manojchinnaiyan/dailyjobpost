### Responsibilities

The Associate Software Engineer I role for this specific position will be a member of the AI powered Automation Factory contributing to test automation. Essential duties and responsibilities include the following.

- Successfully complete required test automation training and onboarding programs
- Understand and follow documented test automation workflows for assigned products
- Generate test automation scripts using established automation frameworks and approved AI‑assisted techniques
- Review and refine AI‑generated test automation code to ensure alignment with test requirements and expected outcomes
- Collaborate with and follow guidance from the Test Automation Lead and Manager to deliver high‑quality automated tests
- Ensure automated tests are stable, maintainable, and compliant with defined coding standards to minimize rework

Human review and accountability of AI generated test automation code is essential for this role.

Success in this role is demonstrated by the ability to produce reliable, maintainable automated tests that integrate seamlessly into the existing automation framework and CI pipelines.
