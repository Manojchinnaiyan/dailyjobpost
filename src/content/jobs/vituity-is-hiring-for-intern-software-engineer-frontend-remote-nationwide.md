### The Opportunity

- Design, build, and maintain frontend features in React and TypeScript for agentic AI products and internal tools.
- Integrate user-facing components with backend services and LLM-driven agent workflows.
- Own a scoped, business-critical project from design through delivery, with weekly mentor and program-lead check-ins.
- Participate actively in code reviews, design discussions, and sprint cycles alongside the engineering team.
- Write tests and contribute to documentation for the features and surfaces they own.
- Engage with backend, design, and product partners to ship work end-to-end.

### Required Experience and Competencies

- Currently enrolled in an accredited college or university in Computer Science, Software Engineering, or a closely related technical field at the rising-senior through in-progress master's level required. Recent graduates within the last 6–12 months may also qualify.
- Demonstrated proficiency in Python with the ability to write, debug, and reason about non-trivial code independently required. Candidates should expect to demonstrate fluency through live coding and code-review discussion; submissions that rely on AI-generated code without underlying comprehension will not meet the bar.
- Demonstrated proficiency in React and TypeScript for production-quality frontend work required.
- Working familiarity with Git, modern frontend build tooling, and standard development workflows required.
- Working knowledge of, or hands-on exposure to, LLM-based agents, tools, or AI-driven application workflows required.
- A public portfolio (GitHub, personal site, or deployed projects) demonstrating frontend or AI-related work is strongly recommended.
- Prior internship, open-source contribution, or substantive personal project work in frontend engineering or AI/LLM tooling preferred.
- Coursework or project experience involving agentic systems, LLM application development, or AI-driven user interfaces preferred.
- 1–2 years of relevant work, club, or volunteer experience in software engineering preferred.
- Strong written and verbal communication skills, particularly in technical contexts.
- Ability to operate independently between weekly check-ins, surfacing blockers proactively rather than waiting to be asked.
- Comfort working in production codebases with established conventions, code review processes, and engineering standards.
- Genuine intellectual curiosity around AI, agentic systems, and emerging engineering patterns.
- Attention to detail in code quality, testing, and incorporation of review feedback.
- Ability to balance multiple workstreams and meet committed deadlines.
- Demonstrated self-learner with interest in continued professional development and personal growth.
