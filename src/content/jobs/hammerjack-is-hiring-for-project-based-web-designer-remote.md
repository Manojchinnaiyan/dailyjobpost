Role: Project-based Web Designer

Location: Remote - with onsite schedules upon client request

### JOB OVERVIEW

We are looking for a project-based Web Designer to support the build and launch of multiple marketing websites over the next 12 months.

The role will focus on translating provided designs into responsive, production-ready websites using Squarespace, Webflow, or similar website-building platforms. This is a remote role suited for someone who can work independently and manage multiple website builds from setup through launch.

### DUTIES AND RESPONSIBILITIES

- Build and maintain websites using Squarespace, Webflow, Wix, or similar no-code platforms
- Translate provided UI/UX designs into responsive web pages
- Configure website structure, CMS collections, forms, and integrations
- Ensure websites are optimized for desktop, tablet, and mobile responsiveness
- Implement basic SEO best practices and website analytics setup
- Perform QA testing, troubleshoot issues, and support website launches
- Apply light custom CSS/HTML/JavaScript when needed
- Collaborate with internal stakeholders to ensure timely delivery of projects

### QUALIFICATIONS

- Proven experience building websites using Squarespace, Webflow, Wix, or similar platforms
- Strong understanding of responsive web design principles
- Experience with CMS setup and content management
- Working knowledge of HTML, CSS, and basic JavaScript
- Familiarity with SEO fundamentals and website performance optimization
- Strong attention to detail and design implementation accuracy
- Ability to manage projects independently in a remote setup
- Good communication and stakeholder management skills
