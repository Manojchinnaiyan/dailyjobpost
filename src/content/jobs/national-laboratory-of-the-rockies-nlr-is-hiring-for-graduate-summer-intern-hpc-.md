### Job Description

The Advanced Computing program at NLR has an opening for a graduate student researcher in High-Performance Computing (HPC) Operational Analytics. The researcher will assist in building the data foundation and AI-driven intelligence infrastructure for the facility, focusing on optimizing the operations of the Kestrel supercomputer.

We are looking for a rigorous, motivated data scientist/engineer with a strong technical background in Python, machine learning, and systems architecture. The successful candidate will collaborate with NLR research scientists to analyze diverse facility telemetry and help build automated, agentic workflows to optimize supercomputing operations and workload scheduling.

Responsibilities include:

- Develop scalable Python pipelines to ingest and analyze diverse HPC telemetry
- Build and evaluate machine learning models to characterize complex HPC workloads
- Assist in developing automated, agentic AI workflows
- Process and package operational data
- Write robust, test-driven code and document data schemas within a collaborative Git repository.
