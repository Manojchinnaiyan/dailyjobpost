- Collaborate with senior engineers to build and enhance web applications based on prioritized business outcomes.

- Learn and apply best practices for version control (Git) and CI/CD pipelines (GitHub Actions).

- Develop RESTful APIs using Node.js and Express, ensuring they follow best practices of performance, scalability, and maintainability.
- Implement SQL queries to interact with databases (MariaDB).
- Gain an understanding of microservices architecture and learn to work within the team’s existing codebase.
- Proactively seek mentorship from both Senior engineers and Staff Engineers to support continuous improvement and growth.

- Foundational proficiency in JavaScript/TypeScript, React, Node.js.
- Basic knowledge of SQL and database queries (MariaDB).
- Familiarity with Git for version control and tools like GitHub Actions for CI/CD.
- Willingness to adapt to changes, demonstrating a growth mindset and a desire to learn.
- Strong problem-solving skills, attention to detail, and a commitment to writing clean, maintainable code.
- Excellent communication skills and openness to constructive feedback.
